## Getting Started

This project needs Node 24 (see `.nvmrc`; with nvm or fnm, run `nvm use` / `fnm use`). `npm install` refuses to run on any other Node version.

Then install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the site.

Other commands: `npm run lint` checks the code, and `npm run build` writes the static site to `out/`. See `AGENTS.md` for the codebase, conventions and how it deploys.
